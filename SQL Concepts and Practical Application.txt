SQL Concepts and Practical Application
1. DDL vs DML
SQL commands are mainly divided into 
i.	DDL (Data Definition Language) DDL is used to define and structure database objects such as tables.
ii.	DML (Data Manipulation Language). while DML is used to manage and manipulate data inside those tables.
DDL (Data Definition Language)Defines database structureCREATE, ALTER, DROP Changes schema Example CREATE TABLE students DML (Data Manipulation Language)Manipulates data in tables INSERT, UPDATE, DELETE Changes records/data Eaxample INSERT INTO students VALUES
2. Use of CREATE, INSERT, UPDATE, DELETE
In this assignment, 
i.CREATE was used to define tables such as students , exam results and subjects.
ii.INSERT was used to add records into the tables. 
iii.UPDATE was used to correct or modify existing data, such as updating a student’s city or changing the students marks that was wrongly input in the exam results table. 
iv.DELETE was used to remove incorrect or cancelled records from the database. In the assignment we deleted result_id 9 from exam results table.
3. Filtering Data Using WHERE
The WHERE clause was used to filter records based on specific conditions. It supports several operators including =, >, <, BETWEEN, IN, and LIKE. 
For example;
i.LIKE was used for pattern matching.  'A%' → starts with A, E%' → starts with E %Studies% → finds "Studies" anywhere in the text
ii.IN was used for multiple values. WHERE city IN ('Nairobi', 'Mombasa', 'Kisumu')
iii.BETWEEN was used for range filtering. It was inclusive - BETWEEN 50 AND 80 includes 50 and 80 themselves.
4. CASE WHEN for Data Transformation
CASE WHEN was used to create conditional logic in SQL queries. It helped transform raw data into meaningful categories. For example in the assignment, exam marks was classified into Distinction, Merit, Pass, and Fail based on score ranges.
